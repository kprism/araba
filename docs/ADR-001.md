# ADR-001: ARABA Initial Architecture

## Status
Accepted

## Context

ARABA is an AI telephone-search platform.

The user describes a real-world information need in natural language.
ARABA determines whether the answer can be obtained from existing data
or whether an AI phone call is required.

The platform must support:

- Android
- iOS
- PC Web/PWA
- AI voice calls
- asynchronous missions
- multi-device notifications
- Fresh Fact DB
- reservation/change/cancellation with user approval

## Decision

ARABA will use a monorepo.

### Mobile
Flutter

### Backend
Python / Django / Django REST Framework

### Database
PostgreSQL

### Queue
Redis + Celery

### Web
PC Web/PWA

### AI
OpenAI API

### Telephony
Twilio/SIP with an alternative voice bridge when required

### Cloud
Google Cloud Platform

## Core Principle

The primary domain object is Mission.

A user does not simply ask ARABA to make a phone call.

The user gives ARABA a goal.

ARABA decides how to obtain the answer.

## Safety Principle

Irreversible or consequential actions such as reservation,
cancellation, payment, or disclosure of personal information
require explicit authorization unless a valid pre-authorization
condition exists.
